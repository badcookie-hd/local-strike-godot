# Godot Engine

The portable Godot executable is intentionally not tracked because the Windows binary is larger than GitHub's 100 MB per-file limit.

Install Godot 4.7 and make `godot`, `godot4`, or `godot4.7` available on `PATH`, or place these files in this directory:

- `Godot_v4.7-stable_win64.exe`
- `Godot_v4.7-stable_win64_console.exe`

The Windows launchers automatically use either setup.
